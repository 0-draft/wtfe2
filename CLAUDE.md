# wtfe2

Bilingual (English default, Japanese at `/ja/`) Astro site that introduces webcomics about software work. Read `README.md` first.

## Invariants

- Only sites whose terms are a Creative Commons license allowing adaptation (`"tier": "translated"`, `"terms.kind": "cc"` in `src/data/sites.json`) may have images in `public/comics/`. Everything else is described and linked; never copy its images, and quote its terms verbatim.
- No ads, sponsorships or affiliate links: every comic here is non-commercial only.
- `en` in a region is the original lettering verbatim; `ja` is a faithful translation with line breaks chosen by hand. Do not invent jokes or drop lines.
- Facts in notes, site blurbs and picks must come from the publisher's own pages (or the strip itself, viewed). Record the check date in `checked`. If something could not be verified, leave it out rather than guess.
- Every user-facing string exists in both languages with the same meaning (`src/lib/i18n.ts`, `src/views/About.astro`, bilingual data fields).
- `public/plates/` and `public/thumbs/` are generated by `scripts/plates.ts`; never commit them.

## Adding or fixing lettering

1. Rough boxes → `pnpm measure public/comics/<slug>.png x,y,w,h ...` → paste the tightened boxes.
2. `pnpm plates <slug>` and look at `public/plates/<slug>.png`: no leftover lettering, no erased drawing. Lettering touching a border needs `"erase": "rect"` with a box that stays off the border.
3. Use `text` when the Japanese needs more room than the original lettering (short labels).
4. `pnpm build && pnpm test:e2e` — the overflow test fails if any lettering leaves its box at desktop or mobile width.

## Checks before committing

`pnpm lint && pnpm lint:md && pnpm check && pnpm validate:data && pnpm test && pnpm build && pnpm test:e2e`
